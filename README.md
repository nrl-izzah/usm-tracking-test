# USM Tracking System (Testing Projek)

Projek ujian ringkas menggunakan PHP, MySQL (XAMPP), dan VS Code untuk latihan GitHub.

## Cara Persediaan
1. Import fail `db.sql` ke dalam **phpMyAdmin**.
2. Pastikan perkhidmatan **Apache** dan **MySQL** aktif di XAMPP Control Panel.
3. Buka projek di penyemak imbas: `http://localhost/usm-tracking-test/index.php`.
